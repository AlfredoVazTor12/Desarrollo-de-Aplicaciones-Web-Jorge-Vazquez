# Desarrollo-de-Aplicaciones-Web-Jorge-Vazquez

# Descripción 

**DevTrack** es una aplicación web estática diseñada para estudiantes de computación y desarrolladores junior. Funciona como un centro de mando integral para organizar proyectos personales, gestionar repositorios, registrar tecnologías dominadas y servir como un portafolio interactivo profesional.
